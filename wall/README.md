# 水槽ウォール（大画面演出）

参加者ごとの制御装置（ポート別）の水位を、**1つの大画面に3Dの水槽を並べて**ライブ表示する。
各自が自分の水槽を攻略し、溢れた瞬間を全員が共有できる（1共有水槽だと得意な人の独壇場に
なるのを回避）。**本物のModbus値で駆動**（攻撃すると本当に水位が動く）。

## 構成
```
各制御装置(run_arena, ポート別) ──Modbus読取── wall.py ──HTTP/JSON── ブラウザ(大画面)
                                                 └ dashboard.html + three.js(同梱) を配信
```
- `wall.py`: 各ポートの水位・コイルを読み、`/state`(JSON) と `dashboard.html` を配信（標準ライブラリのみ）。
- `dashboard.html`: Three.js で水槽をグリッド表示（1行最大4、満水で赤＋しぶき）。`/state` を0.25秒毎に取得。
- `vendor/three.min.js`: オフライン用に同梱（会場はネット無しのためCDN不可）。

## 使い方（当日・Mac）
```bash
# 1) 参加者分の制御装置を起動（例: 8人）
python3 ctf/run_arena.py --count 8 --host 0.0.0.0
# 2) 水槽ウォールを起動
python3 wall/wall.py --count 8
# 3) ブラウザで http://localhost:8090 を開き、プロジェクタ出力で全画面(F11/⌃⌘F)
```
`--base-port`（既定5020）は run_arena と合わせる。`--serve-port`（既定8090）は表示用ポート。

## 挙動
- 青=正常、赤=安全無効 or 溢水。水位はポンプ給水でリアルタイムに増減。
- 参加者が自分のポートを攻撃して100%にすると、その水槽が赤く溢れ、しぶきが飛ぶ。
- 制御装置が落ちている枠は「online:false」（水位は最後の値のまま）。

## 動作確認済み
4ポートで arena→wall→1〜2ポートを攻撃→該当水槽のみ溢水、他は正常、を確認（スクショ検証済み）。
