# 持ち帰り課題 — 制御ステーションをぶっ壊してフラグを出せ（JRU不要）

当日やりきれなかった人向けの持ち帰り謎。**自分のPC（Windows/Mac/Linux）だけで完結**する。
ネットワークも JRU も要らない。`python3` が入っていれば動く。

## ストーリー

EWS（制御PC）は、ディスク上の「制御プロジェクト」`project.cfg` を読んでタンクを安全に制御している。
**このプロジェクトを壊す／改ざんする／消す**と、安全が崩れてタンクが**溢水（物理被害）**する。
溢れた瞬間、フラグが出る。

> OTの教訓そのもの: 本当に怖いのは、制御PCの**ディスクに残る永続的な被害**。
> 今回はそれを手元で安全に体験する（本物のOSは壊さない。壊すのは `project.cfg` だけ）。

## 遊び方

```bash
cd ctf/takehome
python3 station.py --setup     # 正常な制御プロジェクトを作る
python3 station.py --run       # 起動。この状態では溢れない（安全に制御される）
# ここからが課題 ↓
#   project.cfg を 壊す/改ざんする/削除する などして、もう一度 --run で溢水させろ。
```

## ヒント（詰まったら順に）

1. `project.cfg` が読めないと、ステーションはどう振る舞う？ まず消してみよ。
2. 安全は **2段** ある（安全インターロック `safety` と 上限水位 `hh`）。片方だけ外しても
   もう片方が止める。**両方**くぐり抜ける必要がある。
3. `safety` を false、`hh` と `stop` を到達不能な大きな値にすれば、ポンプは止まらない。

## 学び

- **フェイルデンジャラス**: 設定が壊れた時に「安全側」でなく「危険側」へ倒れる実装は脆い。
  本来は、読めなければ運転停止（フェイルセーフ）にすべき。
- **多層防御**: 安全が2段あると、1つ破られてももう1段が守る（ケース: `safety`だけ無効では溢れない）。
