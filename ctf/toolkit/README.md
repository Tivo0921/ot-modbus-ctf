# 参加者キット — OT-CTF（早見表）

> **詳しい説明・ルール・Wireshark手順は、CTFd の「はじめに」ページが正本です**
> （`http://<司会が伝えるIP>:8000` → 上メニュー「はじめに」）。このREADMEは手元用の早見表です。

対象は**貯液タンクの水位を制御する制御装置（PLC）**。Modbus/TCP で通信します。
設計図（どの番号が何か）は渡されません。自分で読み書きして突き止め、最後はタンクをあふれさせます。

## 接続先

- 制御装置: **`<司会が伝えるIP>:<司会が伝えるポート>`**
  - **ポートは参加者ごとに違います**（5020〜）。司会が指定します。
  - コマンドには必ず `--port <自分の番号>` を付ける。
- CTFd（問題・フラグ提出・ツール入手）: `http://<司会が伝えるIP>:8000`

## レジスタとコイル（2種類のデータ）

どちらも番号で指定して読み書きします。

- **保持レジスタ**: 16bit の**数値**の箱（0〜65535）。水位・設定値・流量など。**文字が埋まることも**。→ `read-hr/write-hr`
- **コイル**: **ON/OFF の1ビット**スイッチ。ポンプ・安全装置など。→ `read-co/write-co`
- 攻撃成功時、装置が**レジスタの高い番号に文字列（フラグ）を書き込む**。それを読んで探す。

## コマンド早見

**番号は 0 から**（`read-hr 0 30` ＝ 0〜29番）。引数は「開始番号→個数」／「番号→値」。

```bash
# <IP> <ポート> は司会が伝えた値に置き換え（全員 --port を付ける）
python3 mbclient.py --host <IP> --port <ポート> read-hr 0 30    # 保持レジスタ 0〜29 を読む
python3 mbclient.py --host <IP> --port <ポート> read-co 0 16    # コイル 0〜15 を読む
python3 mbclient.py --host <IP> --port <ポート> write-co 5 1    # コイル5 を ON(1)/OFF(0)
python3 mbclient.py --host <IP> --port <ポート> write-hr 11 65535 # レジスタ11 に 65535
```

| コマンド | 意味 |
|----------|------|
| `read-hr <開始番号> <個数>` | 保持レジスタを読む（16bit 数値） |
| `read-co <開始番号> <個数>` | コイルを読む（ON/OFF） |
| `write-co <番号> <0/1>` | コイルを書く（ポンプ・安全装置） |
| `write-hr <番号> <値>` | レジスタを書く（設定値の改ざん） |

## フラグ

- 形式は **`FLAG{...}`**。見つけた文字列をそのまま CTFd に提出。
- **偵察(1問目)だけ**は装置内に文字列が無く、答えの「番号」を自分で `FLAG{番号}` にして提出。

## Wireshark（平文を見る）

- キャプチャするのは**自分の Wi-Fi**（`192.168.x.x` のアダプタ。WSLは物理Wi-Fi）。loopback ではない。
- 表示フィルタ `tcp.port == <自分のポート>` ／ 本文検索 `frame contains "FLAG"`。
- 右下のバイト列(ASCII)ペインで隠し文字列が読めます。

## ルール

- **本編（レジスタの意味を推定してあふれさせる部分）は AI 禁止**。Wireshark や Modbus 全般の調べ物は可。
- 詰まったら**司会にヒント**を。
- **隔離ネットワーク専用**。渡された制御装置以外には絶対に接続しない。
